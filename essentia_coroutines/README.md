# Essentia Coroutines

Coroutines for [Essentia](https://github.com/davils-com/essentia#readme): structured concurrency with jobs, scopes and
dispatchers, channels, `select`, hot flows on Dart's `Stream`, stream operators, fair locks, the
in-process event bus and the principal in the coroutine context.

| Library | What it holds |
|---|---|
| `package:essentia_coroutines/essentia_coroutines.dart` | Coroutines, channels, `select`, flows, locks, the event bus |
| `package:essentia_coroutines/testing.dart` | `runTest` on a virtual event loop, `TestScope`, `TestScheduler` and the test dispatchers |
